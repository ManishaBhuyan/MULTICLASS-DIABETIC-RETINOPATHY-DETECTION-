Multi-Class Diabetic Retinopathy Detection (Final Year Research Project)

Privacy & Code Availability Notice: This repository provides the architectural overview, preprocessing workflow, and evaluation methodology for our B.Tech final-year group research project. The source code, dataset splits, and trained model weights are intentionally kept private to protect our team's academic research and intellectual property.

Project Overview

Diabetic Retinopathy (DR) is a progressive retinal disease and a leading cause of preventable blindness. Early and accurate staging across severity levels is critical for timely clinical intervention.

This research project implements an automated multi-class classification pipeline using Machine Learning (ML) and Deep Learning (DL) techniques in Python to detect and classify retinal fundus images across multiple clinical severity stages.

System Architecture & Pipeline

Data Collection & Preprocessing

Curated labeled retinal fundus image datasets spanning multiple diabetic retinopathy severity grades.

Applied image resizing, pixel intensity normalization, noise reduction, and data augmentation techniques in Python to address multi-class imbalance and improve generalization.

Model Training & Experimentation

Developed and benchmarked traditional Machine Learning algorithms alongside Deep Learning convolutional architectures for automated spatial feature extraction and multi-class prediction.

Tuned hyperparameters and regularization strategies to prevent overfitting on medical imaging data.

Evaluation & Validation

Evaluated model reliability across all severity classes using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix analysis.
